====================================================
1. ESTRUCTURA GENERAL
====================================================

Mantener el sidebar izquierdo de ScoutFlow.

El menú "Jugadores" debe aparecer seleccionado con el color naranja corporativo de ScoutFlow.

En la parte superior:

Jugadores > [Nombre del jugador]

Utilizar breadcrumb.

La página debe ocupar todo el espacio disponible y utilizar una estructura de dashboard profesional.

Tema:

- Dark mode premium.
- Fondo negro/azul muy oscuro.
- Tarjetas ligeramente más claras.
- Bordes sutiles.
- Color naranja ScoutFlow como color principal.
- Verde para datos positivos.
- Rojo para datos negativos.
- Amarillo para alertas.
- Tipografía moderna y limpia.
- Mucho espacio y buena jerarquía visual.

NO utilizar colores chillones.
